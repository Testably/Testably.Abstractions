# FileSystemWatcher

`MockFileSystem` ships a fully functional [`FileSystemWatcher`](https://learn.microsoft.com/en-us/dotnet/api/system.io.filesystemwatcher) replacement. It fires the same events as the real one - and crucially, it fires the **OS-specific** events that the real watcher fires on Linux, Windows and macOS.

## Basic usage

```csharp
var fileSystem = new MockFileSystem();
fileSystem.Initialize().WithSubdirectory("vault");
fileSystem.File.WriteAllBytes("vault/red-square.png", []);

using var watcher = fileSystem.FileSystemWatcher.New("vault");
var artworkRemoved = new ManualResetEventSlim();

watcher.Deleted += (_, _) => artworkRemoved.Set();
watcher.EnableRaisingEvents = true;

fileSystem.File.Delete("vault/red-square.png");

await Expect.That(artworkRemoved.Wait(TimeSpan.FromSeconds(1))).IsTrue();
```

## Reacting to triggered events from a test

`MockFileSystem.Watcher.OnTriggered(...)` returns an [awaitable callback](./intercept-and-notify) that fires after every `IFileSystemWatcher` event. Use it to assert what a watcher saw without subscribing to the event yourself:

```csharp
MockFileSystem fileSystem = new();
fileSystem.Initialize().WithSubdirectory("vault");

using var watcher = fileSystem.FileSystemWatcher.New("vault");
watcher.EnableRaisingEvents = true;

// highlight-next-line
using var triggered = fileSystem.Watcher.OnTriggered();

fileSystem.File.WriteAllBytes("vault/blue-circles.png", []);
WatcherChangeDescription[] events = triggered.Wait(count: 1);
```

## Which events are raised

When an entry is moved, the events depend on where it comes from and where it goes, relative to the watched path:

```text
storage/                     ← Outside
vault/                       ← the watched path
├── red-square.png           ← Inside
└── sketches/
    ├── blue-circles.png     ← Nested
    └── drafts/
        └── yellow-lines.png ← Deep
```

`_` stands for "nothing", i.e. the entry is created (`_ → Inside`) or deleted (`Inside → _`), and `-` means no event is raised. Pick the value of `IncludeSubdirectories`:
