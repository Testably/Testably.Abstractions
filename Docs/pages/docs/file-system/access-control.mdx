# Simulating access denial (ACL)

To simulate Windows access control list (ACL) restrictions, register an `IAccessControlStrategy` with `WithAccessControlStrategy(...)`.

The built-in `DefaultAccessControlStrategy` takes a callback `(fullPath, extensibility) => bool` - return `false` to deny access to that path. Operations on a denied path then throw `UnauthorizedAccessException` with the message `"Access to the path '{fullPath}' is denied."`, like the real Windows file system:

```csharp
MockFileSystem fileSystem = new();
// highlight-start
fileSystem.WithAccessControlStrategy(
    new DefaultAccessControlStrategy((path, _) => !path.EndsWith("secret.txt")));
// highlight-end

fileSystem.File.WriteAllText("public.txt", "x"); // ok
fileSystem.File.WriteAllText("secret.txt", "x"); // throws UnauthorizedAccessException
```

:::warning[Windows-only]
`WithAccessControlStrategy` throws `PlatformNotSupportedException` on non-Windows hosts (and when simulating a non-Windows OS). ACL functionality is intentionally tied to Windows behaviour.
:::

## Reading and writing ACL objects

This page is about *denying* access. To read and write `FileSecurity` / `DirectorySecurity` objects (the `GetAccessControl` / `SetAccessControl` APIs), install the [`Testably.Abstractions.AccessControl`](../companion-libraries/access-control) companion package.
