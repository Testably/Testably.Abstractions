# Benchmarks

These benchmarks compare Testably.Abstractions with [System.IO.Abstractions](https://github.com/TestableIO/System.IO.Abstractions) for the same calls. The mock file system of Testably.Abstractions models more of the real behavior, such as file locks, timestamps and the rules of each operating system, so some of its extra time is the cost of behaving like the real file system.

<Tabs groupId="abstractionsBenchmark" className="benchmark-tabs">

<TabItem value="Complete" label="Complete test" default>

A complete unit test: seed a small project, let the code under test read its configuration, write the sources into one output file, back it up and delete a source, then check the result. Both libraries run the same calls.

<AbstractionsBenchmarkResult name="Complete" />

```csharp
MockFileSystem fileSystem = new();
fileSystem.Directory.CreateDirectory("project/src");
fileSystem.File.WriteAllText("project/config.json", "{\"output\":\"out/bundle.txt\"}");
for (int i = 0; i < 5; i++)
{
    fileSystem.File.WriteAllText($"project/src/file{i}.cs", $"class C{i} {{ }}");
}

string config = fileSystem.File.ReadAllText("project/config.json");
fileSystem.Directory.CreateDirectory("project/out");
using (StreamWriter writer = fileSystem.File.CreateText("project/out/bundle.txt"))
{
    foreach (string file in fileSystem.Directory.EnumerateFiles("project/src", "*.cs"))
    {
        writer.WriteLine(fileSystem.File.ReadAllText(file));
    }
}

fileSystem.File.Copy("project/out/bundle.txt", "project/out/bundle.bak");
fileSystem.File.Delete("project/src/file0.cs");
```

<details>
<summary>How these numbers are measured</summary>

- **Suite**: [`Testably.Abstractions.Benchmarks`](https://github.com/Testably/Testably.Abstractions/tree/main/Benchmarks/Testably.Abstractions.Benchmarks) driven by [BenchmarkDotNet](https://benchmarkdotnet.org/).
- **Job**: `MediumRun` with the in-process toolchain on .NET 10.
- **Runner**: `ubuntu-latest` GitHub Actions agent, refreshed on every push to `main`.
- **Parameters**: the enumeration benchmark runs with 10 and 1,000 files (`N=10`, `N=1000`) and with the patterns `*` and `*.txt`, each combination selectable in the chart.
- **Charts**: every multiple is relative to Testably.Abstractions, and bars longer than four times the fastest library are cut so the others stay comparable. Lower is better.

</details>
